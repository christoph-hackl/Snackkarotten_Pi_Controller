\section{Gesamtsystem und Architektur}
Das System besteht aus zwei Recheneinheiten. Der Raspberry Pi 5 übernimmt die Hauptlogik. Dazu gehören zum Beispiel Bildverarbeitung, Ablaufsteuerung und Entscheidungen im Programm. Außerdem bindet er Bausteine wie zum Beispiel die IMUs und den I\textsuperscript{2}C Servo Controller an.

Der STM32H562RIT6 übernimmt die Motoransteuerung und analoge Sensorsignale. Die Kommunikation zwischen Raspberry Pi und STM32 läuft über UART.
Der STM32 wird über SWD programmiert und debuggt.
