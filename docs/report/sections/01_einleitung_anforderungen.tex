\section{Einleitung}
In dieser Projektarbeit wurde eine Erweiterungsplatine für den Raspberry Pi entwickelt. Ziel war es, die wichtigsten Funktionen für Robotik- und Schulprojekte auf einer Platine zusammenzufassen.

Die Platine verbindet den Raspberry Pi 5 mit Motoren, Servos, Sensoren, IMUs und der Spannungsversorgung. Ein STM32-Mikrocontroller übernimmt Aufgaben, die zeitkritisch sind oder analoge Eingänge brauchen.

Diese Dokumentation beschreibt den aktuellen Stand der Platine. Es geht um den Aufbau, die Bauteile, wichtige Entscheidungen, erkannte Fehler und mögliche Verbesserungen.

\section{Ausgangslage, Zielsetzung und Anforderungen}
Der Raspberry Pi hat genug Rechenleistung für Robotikprojekte. Er ist auch softwareseitig sehr flexibel. Für einen Roboter hat er aber auch Nachteile. Er hat keine Analogeingänge. Außerdem ist Linux für sehr zeitkritische Aufgaben nicht ideal.

Deshalb wurde eine eigene Erweiterungsplatine entwickelt. Sie soll viele benötigte Funktionen direkt auf einem Board bereitstellen. Dadurch wird der Aufbau kompakter und robuster.


\subsection{Systemanforderungen}
\begin{itemize}
	\item Der Raspberry Pi muss als zentrale Recheneinheit direkt auf die Platine aufgesetzt werden können.
	\item Mehrere DC-Motoren müssen über passende Treiber angesteuert werden können.
	\item Servos müssen über eigene Anschlüsse und getrennte Versorgungsbereiche betrieben werden können.
	\item Digitale und analoge Sensoren müssen ohne Zusatzboards anschließbar sein.
	\item Mindestens ein IMU-System für Bewegungsdaten muss vorhanden sein.
	\item Der STM32 muss zeitkritische Aufgaben übernehmen und mit dem Raspberry Pi kommunizieren können.
\end{itemize}

\subsection{Konstruktive Anforderungen}
\begin{itemize}
	\item Leistungselektronik und Logikbereich sollen möglichst sauber getrennt werden.
	\item Die Leiterplatte soll mechanisch und elektrisch für den Robotikeinsatz geeignet sein.
	\item Die Plattform soll auch für spätere Projekte weiterverwendbar sein.
\end{itemize}
